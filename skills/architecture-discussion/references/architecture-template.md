# Template for presenting one architecture

Use these headings in the reply and in the notes (`### Architecture N: <name>`).

1. **In one sentence**: what it is.
2. **How it works**: deployment unit, main parts/modules/services, how they communicate, where data lives.
3. **Simple example**: one end-to-end flow from the requirements (for example cart submission to payment confirmation and shipment tracking), step by step.
4. **Main parts** (table: part, responsibility, owns data?).
5. **Advantages** (specific to the requirements, not generic).
6. **Disadvantages**.
7. **How it differs from the previous architecture(s)**: deployment, data, transactions, operations, failure behavior.
8. **Main technical challenges** (see the technical checklist).
9. **Fit with the requirements**: what in the source supports it, what does not. Note which statements are assumptions.
10. **Open questions** it raises.

Keep each section short. Use plain language and one example before technical terms.
